# 雾屿航线 2D 版设计文档

这份文档是 2D 版的总说明书。开工前、接手时、上下文被压缩之后，都先读这一份。它和代码冲突时，以这份文档为准，并且要回来改文档；数值以 `src/config/` 为准。

- 文字版已冻结在 `text-version` 分支：只修 bug，不加功能。
- 2D 版在开发分支上做，合并后成为 `main`。
- 美术设计稿：`design/2d-美术设计稿-B.html`（浏览器直接打开，可以拖时间条、开木筏）。
- 文字版的规则细节：`docs/game-systems.md`（2D 版沿用其中的数值和顺序，改动的地方在本文“规则改动”里列出）。

## 1. 定位与原则

**一句话**：一个人坠机在雾里的群岛上，修灯塔照开迷雾，划木筏找回六个同伴，把一座座小岛连成会自己运转的贸易网络，最后修好直升机去进出口局报到。

**操作参照星露谷物语**：人物在地图上自由走动，走到东西旁边按 E 就是和它互动。世界里看得见的东西就是功能本身，不藏在菜单里。

### 七条原则

1. **一个建筑一个功能。** 工作台只管制作，储物箱只管存取，床只管睡觉，码头只管出海。玩家看见建筑就知道它能干什么。一个功能也只放在一种建筑上，不在两个地方都能做。
2. **东西在世界里。** 采集点、设施、请求、商店都是地图上的实物。面板是“打开这个东西”的结果，不是全局菜单。全局面板只有背包、海图、目标、帮助、设置。
3. **引导充足，一次只说一件事。** 屏幕上同时最多一个当前目标、一条提示、一个高亮。新东西第一次出现时一定有人告诉玩家它是什么、怎么用。
4. **不乱。** 同一时间只开一个面板，Esc 一律关闭。HUD 固定在四个角，元素有数量上限（见第 9 节）。新功能按进度逐步出现，用不上的不显示。
5. **只用 12 色。** 画面里的一切都来自 B 方案调色板。白天、黄昏、夜晚靠换色表变化，不叠半透明。
6. **自由移动，格子只记数据。** 岛上走路、海上划木筏都用连续坐标。16 像素的格子只用来记录哪里被照亮、哪里去过、哪里能走。
7. **规则沿用文字版。** 时间、生存、产能、交付、运输的数值和剧情顺序照搬文字版，除非本文明确写了改动。

## 2. 与文字版的关系

| 部分 | 处理 |
| --- | --- |
| `src/config/`（数值、物品、配方、岛屿、村落） | 保留，按 2D 需要增加字段（建筑、地图模板、坐标） |
| `src/i18n/`（中英文字） | 保留并扩充；剧情和对白直接沿用 |
| `src/sim/` 里纯规则的函数（吃饭、产能、交付、运输结算、战斗、升级） | 逐个评估，合适就复用，不合适就改写 |
| `src/sim/` 里的地图、移动、迷雾格子、新手引导 | 重写 |
| `src/ui/`（React 界面） | 重写为 2D 界面层；可以参考布局和文字 |
| 存档 | 新格式，不读文字版存档 |
| 自动通关测试（`sim/bot.ts`） | 保留思路，改成驱动 2D 版的命令 |

**原则**：文字版是 2D 的原型，不是要背着走的包袱。复用旧代码以“不让 2D 版变别扭”为前提。

### 规则改动（2D 带来的变化）

| 文字版 | 2D 版 | 原因 |
| --- | --- | --- |
| 制作“随时随地”，海上也能做 | 只能在**工作台**做（主岛开局就有；网络里的每座岛都有一张） | 一个建筑一个功能 |
| 岛上仓库是面板里的一栏 | 仓库就是岛上的**储物箱**，走过去按 E 存取 | 同上 |
| 木筏货舱在面板里 | 货舱在**码头**旁的木筏上；在码头或海上按 Tab 可以看货舱 | 货在船上 |
| 海上按格子移动，每格 7 分钟 | 连续移动，每航行 16 像素推进 7 分钟，另外实时流逝 | 自由移动 |
| 海上事件“每格 5%” | 每航行 16 像素检定一次，概率不变 | 同上 |
| 航行 Lv5 一次走两格 | 航行等级提高木筏最高速度（每级 +5%） | 没有“格”了 |
| 靠岸 / 离开是按钮 | 在岸边按 E 靠岸，在码头按 E 出海 | 星露谷式交互 |
| 交付在需求面板里 | 和要东西的人说话（或在村落请求板）交付 | 同上 |
| 喝海水、跳海捕鱼在顶栏 | 海上按 Z / X；岛上站在水边按 Z 喝海水 | 同上 |
| 掰树枝、捞鱼、采草药是按钮 | 走到树、浅滩、草药丛旁按 E，播放短动作 | 同上 |
| 主岛的树和草药是固定的，草药一共 5 份 | 树和草药丛每天早上在岛上的几片区域里随机长出来；每棵树只能出 3–5 根木头、每丛草药 1–2 份，采完树变成树桩、草丛变空，第二天早上清掉再长新的。只影响玩家手动采集，岛上设施（伐木场等）的产能不受影响。数值在 `BALANCE.forage`，区域在地图模板的 `forage` | 手动采集要有限度，每天都有新的事做 |
| 自己采到、捕到的东西先放货舱 | 先放背包（马上看得到），满了才进货舱 | 放进看不见的地方等于丢了 |
| 货舱和加固货舱在面板里 | 海上按 Tab 看货舱；岛上在码头边的木筏旁装卸、改造 | 东西在世界里 |
| 只有主岛能采集 | 每座岛按群系长树和草药，渔场岛有浅滩钓点 | 每座岛按类型有基础物资 |
| 岛连续吃饱 6 顿自动升级 | 吃饱 6 顿是条件，在设施旁交材料手动升级 | 升级是玩家自己做的一步，地点在设施旁 |
| 仓库里的淡水只能由岛民喝 | 在储物箱旁可以直接吃喝仓库里的东西 | 同上 |
| 背包 16 件、货舱 30 件（按件数算） | 背包 12 格、货舱 24 格（每次加固 +6 格）。每格放一种东西，按种类有堆叠上限：能吃喝用的 10 个，其他原料 20 个。飞机零件不占格子。岛上的储物箱也按格子算（主岛 24 格，网络岛 1/2/3 级 12/18/24 格）；淡水放单独的水缸（主岛 60，网络岛 30/60/90） | 2D 里画的是格子，按件数算会和看到的对不上；仓库和背包同一套规则才不会两样 |

其他规则（生存消耗、睡觉、死亡、吃饭、升级、犯困、培训、运输、村落请求、终局）不变，详见 `docs/game-systems.md`。

## 3. 操作

### 键盘

| 键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 移动（岛上走路，海上划木筏） |
| E | 互动：和面前的东西或人互动；岸边靠岸，码头出海 |
| X | 跳海捕鱼（只在海上） |
| Z | 喝海水（海上，或岛上站在水边） |
| F | 捞起漂流物（附近有漂流物时） |
| Tab | 背包（在码头或海上时多一页“货舱”） |
| M | 海图 |
| J | 目标与日志 |
| H | 帮助 |
| Esc | 关闭面板；没有面板时打开菜单（继续、设置、存档、回到欢迎页） |
| 1–5 | 快捷栏：选中一样东西；按 Q 吃 / 喝选中的东西 |

### 手机

- 左下虚拟摇杆移动，右下一个大的“互动”按钮（显示当前能做的事，比如“掰树枝”），旁边是 X / Z / F 的小按钮，只在可用时出现。
- 顶部一行：时间、生命 / 水 / 食物；右上“菜单”按钮里是背包、海图、目标、帮助、设置。
- 面板全屏显示。

### 互动规则

- **互动范围**：人物前方 16 像素内、离人物最近的一个可互动物体。只有一个对象会被选中。
- **选中显示**：被选中的东西描一圈灯芯色的 1 像素轮廓，头顶出现按键提示“E 掰树枝”。
- **按键提示**跟在人物头顶，最多 3 条，按优先级：警告（“雾太浓，过不去”）> E（当前互动）> F > X / Z。只显示现在真的能做的事；做不了时显示原因，比如“E 睡觉（18:00 以后）”变灰。
- **动作耗时**：采集、制作这类动作会播放一段短动作（0.6–1.2 秒），同时推进对应的游戏时间（数值同文字版）。动作期间不能移动，按 Esc 可以中断。
- **一个东西一个主动作。** 有多个选项的建筑（比如设施要“查看 / 培训”）按 E 打开它自己的面板，在面板里选，不在世界里堆多个按键。

## 4. 场景

| 场景 | 内容 | 进出 |
| --- | --- | --- |
| 欢迎页 | 继续 / 新的旅程、语言、设置 | 打开游戏 |
| 开场剧情 | 5 段背景故事（沿用 `intro.0–4`），可跳过 | 新游戏 |
| 岛上 | 每座岛一张地图，人物步行 | 在岸边按 E 靠岸进入，出生在码头；在码头按 E 出海离开 |
| 出海 | 整个群岛的海面，木筏自由航行 | 从码头出海；靠岸后切回岛上 |
| 海图 | 全图总览：照亮范围、去过的地方、岛、目标、运输线 | 任何时候按 M；只看不走 |
| 界面层 | HUD、面板、弹窗 | 叠在场景上 |
| 过场 | 获救、试飞、结局 | 剧情触发 |

- **镜头**：画面是 480 × 270 个游戏像素，跟随人物或木筏，在地图边缘停住。只按整数倍放大（1080p 4 倍）。画布按屏幕分辨率渲染，镜头和人物可以移动不到一个游戏像素，走路顺滑（见“M1 实现记录”）。
- **地图大小**：海面 60 × 36 格（960 × 576 像素），和文字版一样。岛屿地图按岛的类型和等级，30 × 17 格到 50 × 30 格不等。
- **切换**：靠岸 / 出海时用一个 0.4 秒的点阵过渡（Bayer 矩阵变黑再亮起，和睡觉同一套）。

## 5. 世界

### 海面

- 迷雾、灯塔、岛屿出现的规则全部沿用文字版（`docs/game-systems.md` 第 3 节）：只有灯塔能照开迷雾；下一座岛在锚点岛灯塔**新照亮**的海域里生成；`REVEALS` 的顺序不变。
- 照亮范围是圆形，按格子记录（`state.lit`）。画面上用点阵雾表现：浓雾挡住木筏，边缘有一圈可以进去但看不清的薄雾。
- 格子状态只决定颜色：迷雾（不能进）、可探索（亮着但没去过，颜色降一档）、已探索（正常颜色，格角有小点）。
- 木筏周围半径 2 格（5 × 5）的已照亮格子标记为已探索；离岛 3 格以内时发现这座岛（同文字版）。
- 海上看得见：岛（海上比例的小号素材）、自己的木筏、运输木筏、漂流物、海鸥、灯塔光束（夜里）。

### 岛屿类型与地图

每座岛按类型用一个**地图模板**生成：固定的地形轮廓规则 + 固定的建筑位置（槽位），用岛的种子做细节变化。

| 类型 | 例子 | 必有 | 可建 |
| --- | --- | --- | --- |
| 主岛 | 主岛 | 码头、小屋（床）、工作台、储物箱、灯塔、直升机残骸、树林、浅滩、草药丛、农田空地 | 停机坪（终局） |
| 乘客岛 | 石头岛、森林岛、渔村、田地岛、草药岛 | 码头、求救的同伴、灯塔地基；获救后出现工作台、储物箱、设施建筑 | 灯塔、床、物资接收点、船坞、停机坪 |
| 原住民岛 | 椰影岛、白鸥岛、碎贝岛 | 码头、原住民、灯塔地基；招募后同上 | 同上 |
| 礁石 | 信标礁 | 码头、信标杆、飞行员 | 灯塔 |
| 配方村 | 潮声村、麦香村、船坞村 | 码头、请求板、学堂、村民 | 灯塔 |
| 人力村 | 人力村 | 码头、请求板、接人点、村民 | 灯塔 |
| 进出口局 | 进出口局 | 码头、出口柜台、升级窗口、订单板、局长室、停机坪 | — |

岛的群系（森林、石头、渔场、田地、草药）决定地面贴图、树和石头的比例，以及设施建筑的样子。

## 6. 建筑与功能（核心）

每个建筑只有一个功能。按 E 打开的就是这个功能。

### 主岛和网络里的岛

| 建筑 / 物体 | 按 E | 出现条件 | 对应文字版 |
| --- | --- | --- | --- |
| 码头 | 出海（有木筏时）。木筏停在码头旁，货舱在船上 | 开局有码头；造好木筏后能出海 | 出海按钮 |
| 工作台 | 制作：列出已学配方，原料从背包、货舱（木筏在码头时）、这座岛的仓库一起扣。也在这里做木筏、加固货舱 | 主岛开局就有；其他岛加入网络时出现 | 制作标签 |

| 直升机残骸 | 维修：安装零件、修飞机（零件和成本同文字版） | 主岛 | 飞机残骸 |
| 树 | 掰树枝（木头 +1，20 分钟）；救出伐木工后改为砍树（+3，30 分钟）。每棵 3–5 根木头，采完变树桩；每天早上随机长出新树 | 主岛 | 掰树枝 |
| 浅滩钓点 | 捞鱼（60% 得 1 条鱼，30 分钟） | 主岛 | 浅滩捞鱼 |

| 农田 | 播种 / 收获（3 块，24 小时成熟，每块 6 小麦） | 救出农民后 | 农田 |
| 设施建筑 | 设施：这座岛在生产或加工什么、工人、产能、库存、状态 | 岛加入网络、完成培训后 | 岛的设施 |
| 物资接收点 | 查看：水和食物多存 40 份 | 建造 | depot |
| 船坞 | 运输线：建造运输木筏（工程师在场）、设置路线和货物 | 工程师学会运输木筏后可建 | 运输面板 |

### 设施建筑的样子

一座岛只有一个设施（同文字版）。设施建筑按它做的事画：

| 设施 | 建筑 | 产出 |
| --- | --- | --- |
| 木头 | 伐木场（木桩 + 柴堆 + 斧头） | 木头 |
| 鱼 | 渔场（晒网架 + 鱼篓） | 鱼 |
| 淡水 | 蒸馏棚（罐头盒蒸馏器） | 淡水 |
| 小麦 | 麦田 | 小麦 |
| 草药 | 药圃 | 草药 |
| 杯子 | 木工坊 | 杯子 |
| 装杯 | 装杯台 | 杯装水 |
| 医疗箱 | 药房 | 医疗箱 |
| 烤鱼 | 烤鱼架 | 烤鱼 |
| 盐 | 晒盐池 | 盐 |
| 面包 | 烤炉 | 面包 |
| 三明治、群岛盛宴 | 厨房 | 三明治、盛宴 |

设施头顶常驻一个小进度条；出问题时头顶换成状态气泡，里面是原因的图标（暂存箱满了、水缸满了、原料不足、无人工作、犯困、停工（断供））。设施旁有自己的**暂存箱**：产物先放这里（淡水直接进水缸），满了就停工。玩家在设施面板里把暂存箱的东西拿到背包或全部放进储物箱，这样仓库里放多少由玩家决定，设施不会一直产到把仓库塞满。

### 人物

人物不是建筑，但同样“走过去按 E”：

| 对象 | 按 E |
| --- | --- |
| 求救的同伴 | 对话；带齐了东西时直接交付并获救 |
| 原住民（未招募） | 对话；交付招募物资 |
| 网络里的同伴、原住民 | 人物面板：状态、接走 / 放下、培训（原住民）、叫醒（犯困） |
| 村民 | 对白（剧情、提示） |

有事可做的人和建筑头顶有一个灯芯色的“!”（可交付、可获救、犯困、新请求）。

## 6.5 玩法梳理（2D 第二版）

文字版里很多规则是因为“只有文字和按钮、难以表达”才做的取舍。2D 里东西都摆在世界里，这一节逐个系统重新想过：哪里沿用、哪里改、什么时候做。改规则的地方同时写进上面的“规则改动”表。

**总原则**：东西放在哪里就要看得见、拿得到；功能放在对应的建筑旁边（一个建筑一个功能）；每座岛按自己的类型有一些基础物资；玩家看不见的“自动发生”的规则，要么让它可见，要么变成玩家自己做的一步。

| 系统 | 文字版 | 2D 版 | 状态 |
| --- | --- | --- | --- |
| 东西放在哪 | 采集到的先进货舱 | 自己捞到、捕到、捡到的都先进**背包**（马上看得到），满了才进货舱；运货的补给才点名进货舱 | 已做 |
| 货舱 | 面板里的一栏 | 货舱在木筏上：海上按 Tab 看货舱，可以和背包互相搬；靠岸后木筏停在码头边，走到**木筏**旁按 E 装卸、全部卸到岛上仓库 | 已做 |
| 木筏改造 | 主岛“建设”里的加固货舱 | 在码头边的**木筏**旁改造（加固货舱，以后船速等也放这里） | 已做 |
| 三种水 | 淡水只能在仓库，要装杯才能带走 | 不变，但仓库里的淡水和食物可以**在储物箱旁直接吃喝**；没有淡水的岛只能站在水边按 Z 喝海水 | 已做 |
| 岛上仓库 | 每种物品各有上限（1 级 40 个），设施产到上限就停 | 储物箱按格子 + 堆叠（和背包一样），岛升级格子变多；淡水放单独的水缸；设施产物先进设施旁的暂存箱，满了停工，玩家决定什么时候、拿多少进仓库 | 已做 |
| 昨日收成 | 睡醒的日志里一句“岛上产出了……” | 每天早上 06:00 弹一张卡：每座网络岛一行（产出的图标格、三顿饭的碗、等级星），最后一行合计；时间暂停，Esc / Enter / E 关闭 | 已做 |
| 设施产物进仓库 | 自动 | 默认留在设施旁的暂存箱，玩家自己收；在设施旁装**自动入库机**（贵）以后自动放进储物箱。运输线从暂存箱和储物箱都拿 | 已做 |
| 带人去别的岛 | 面板里点“上船 / 下船” | 走到那个人旁边说话“跟我上船”；到岛上在码头边的木筏旁“下船”；木筏上画出同行的人 | 已做 |
| 培训 | 岛面板里的一栏 | 在设施旁的“培训”分页（还没有设施的原住民岛是设施地基）：选学生、老师、工作 | 已做 |
| 每座岛的码头 | 靠岸 / 离开是按钮 | 每座岛都有码头，从码头出海；木筏停在码头边 | 已做 |
| 岛的基础物资 | 只有主岛能采集 | 每座岛按群系长树和草药（森林岛树多、草药岛草药多），渔场岛有浅滩钓点；任何岛上都能采 | 已做 |
| 设施 | 岛的一个属性，面板里一行字 | 加入网络、有了工作的岛上出现**设施建筑**（蒸馏棚、伐木场、渔场、麦田、药圃、烤鱼架、烤炉、晒盐池），头顶有进度条，停工时换成“!”；按 E 看产出、工人、库存、吃饭情况 | 已做 |
| 自动产水 | 救出工程师后石头岛每小时产 1.5 份淡水（看不见） | 规则不变；现在石头岛上有蒸馏棚，产出和库存在设施面板、储物箱里看得到 | 已做 |
| 岛的升级 | 连续吃饱 6 顿自动升级 | 连续吃饱 6 顿是**条件**；到设施旁点“升级”并交材料才升级（`BALANCE.economy.upgradeCost`）。吃饱够了日志会提醒 | 已做 |
| 灯塔 | 只有照亮范围 | 每座修好的灯塔夜里都亮灯、有光束（岛上和海上） | 已做 |
| 培训 | 面板里选人选工作 | 在**设施**旁培训（培训的同伴要在场：在岛上或在木筏上） | M3（要先能带人上船） |
| 带人上船 | 面板里接走 / 放下 | 和人说话时“上船 / 下船”，人坐在木筏上跟着走 | M3 |
| 床、仓库、停机坪 | 建设列表 | 网络岛上的空地有**建设地基**木牌，按 E 选建小屋（床）、仓库、停机坪（修好飞机以后）；建好的房子出现在岛上 | 已做 |
| 村落请求 | 村落面板 | **请求板**（村长站在旁边）：全部请求一行一个，奖励一开始就看得见（像星露谷社区中心的收集包），按 E 交付；配方在村里的**学堂**学 | 已做 |
| 运输线 | 面板里设路线 | 主岛的**船坞**：造运输木筏、培训船员、开通运输线；运输木筏在海上真的开来开去 | 已做 |
| 犯困 | 面板里“叫醒” | 犯困的设施头顶冒“Z”，走过去按 E 直接叫醒 | 已做 |

还要想清楚、留到对应里程碑再定的：

- 主岛有没有自己的设施（现在主岛靠玩家手动采集和制作，没有设施）。
- 设施升级的材料是否按岛的产物来定（现在两级统一：木头 + 鱼、木头 + 杯装水）。
- 网络岛上的树和草药是否也给岛民用（现在只有玩家手动采，岛民只靠设施）。

## 7. 系统规则摘要

以下只写要点和 2D 改动，完整规则和数值见 `docs/game-systems.md` 与 `src/config/balance.ts`。

### 时间

- 1 游戏小时 = 现实 37.5 秒。开局第 1 天 07:00。白天 06–19、黄昏 19–22、夜晚 22–06。
- 动作耗时沿用文字版；航行每 16 像素 7 分钟。
- 打开面板时时间**不**暂停（和星露谷一样）；菜单、帮助、剧情、新配方弹窗时暂停；页面隐藏时暂停。
- 画面换色另有 5 个视觉时段（黎明、白天、傍晚、黄昏、夜晚），过渡 60 游戏分钟，见第 10 节。只影响画面。

### 生存与死亡

- 生命 / 水 / 食物、每小时消耗、夜里在海上和无床岛掉血、喝海水、跳海捕鱼、死亡惩罚：全部同文字版第 2 节。
- 死亡：屏幕点阵变黑，在最近的床上醒来，日志写明丢了什么。

### 物品与存放

- 位置：背包（12 格，随身）、货舱（24–42 格，在木筏上）、储物箱（每座网络岛的仓库，格子 + 堆叠，格数随岛等级变多）、水缸（淡水，容量随等级变大）、设施暂存箱（产物先放这里，每级 2/3/4 格，满了停工）。
- 岛民吃饭先从储物箱和水缸里拿，不够再拿暂存箱里的（干活的人吃自己刚捕的鱼）。
- 格子和堆叠：每格一种东西；能吃喝用的一格最多 10 个，其他 20 个；零件不占格子。数值在 `BALANCE.inventory`。
- 三种水：海水（站在水边按 Z 喝，伤身）、淡水（散装，只在水缸里，储物箱旁能喝、能装杯）、杯装水（能带走、交付）。
- 快捷栏显示背包前 5 格；可以吃喝的东西按 Q 直接用。

### 制作

- 在工作台做。原料来源：背包 + 这座岛的仓库 + 货舱（木筏停在这座岛的码头时）。产物进背包，满了进仓库。
- 配方、原料、耗时、绑定同伴同文字版第 12 节。运输木筏在船坞造。

### 出海

- 木筏：加速 140 像素/秒²，最高 50 像素/秒（航行等级每级 +5%，终局船速升级另乘），阻力让木筏松手后约 1 秒停下；撞岸反弹 20%。
- 浓雾挡路；靠近岸边 16 像素内出现“E 靠岸”。
- 海上事件（蜜蜂、鲨鱼、漂流物、剧情线索）按航行距离检定，规则同文字版第 5 节。战斗用一个小面板，显示双方武力和结果。
- 漂流物画在海面上，靠近按 F 捞起。

### 经济、人物、村落、运输、终局

- 同文字版第 8–14 节。界面入口换成对应建筑（第 6 节）。
- 运输木筏在海面上按路线（先横后竖）实际航行，速度按文字版换算：30 分钟一格。

### 目标

- 目标顺序同文字版第 15 节。当前目标写在右上角，带进度和方向。

## 8. 引导

目标：第一次玩的人不看帮助也能玩下去，但屏幕上永远不乱。

### 分层

1. **开场剧情**：5 段，可跳过。
2. **第一天脚本引导**（见下表）：一步一件事，做完才出下一步。
3. **当前目标**（右上角）：一个标题 + 一行说明 + 进度。
4. **世界标记**：目标对应的东西头顶有一个上下跳动的箭头；目标在屏幕外时，屏幕边缘有一个指向它的小箭头和距离。
5. **按键提示**：人物头顶，告诉玩家现在能按什么。
6. **初见介绍**：第一次走近一种建筑或采集点时，它头顶出现一张小卡：名字 + 一句话功能（“工作台：用材料制作物品”）。每种只出现一次。
7. **情境提示**：需要整段说明的才用（天快黑、三种水、原住民、村落、犯困、进出口局），左下角一张卡，几秒后收起，同一时间最多一条。
8. **帮助（H）和日志（J）**：随时可查。

### 第一天脚本

| 步 | 触发 | 高亮 / 箭头 | 说明（当前目标） | 完成 |
| --- | --- | --- | --- | --- |
| 1 | 剧情结束，人物在残骸旁醒来 | 人物 | 用 WASD 走动 | 走出 3 格 |
| 2 | — | 最近的树 | 走到树旁按 E 掰树枝 | 木头 ≥1 |
| 3 | 木头 ≥1 | 树 | 再掰几根，造木筏要 8 根木头（n/8） | 木头 ≥3 |
| 4 | 木头 ≥3 | 浅滩钓点 | 去浅滩捞条鱼，路上吃得着 | 鱼 ≥1 或木头 ≥8 |
| 5 | 木头 ≥8 | 工作台 | 去工作台做木筏 | 造好木筏 |
| 6 | 造好木筏 | 状态条 | 介绍生命 / 水 / 食物和喝海水 | 看过 |
| 7 | — | 码头 | 去码头按 E 出海 | 出海 |
| 8 | 第一次出海 | 屏幕边缘箭头 | 石头岛在东北方向，跟着箭头划过去 | 靠近石头岛 |
| 9 | 靠近岸 | 人物头顶“E 靠岸” | 按 E 靠岸 | 登岛 |
| 10 | 登上石头岛 | 工程师头顶“!” | 和工程师说话，给他 3 条鱼 | 救出工程师 |
| 11 | 救出工程师 | 灯塔地基 | 修灯塔，下一座岛会出现在新照亮的海域 | 修好 |

- 每步只有一个高亮。高亮用灯芯色描边 + 头顶箭头，不调暗全屏。
- 玩家可以不按顺序做；某一步的条件已经满足时直接跳过。
- 18:00 以后不管在哪一步，都插一条“天快黑了，回主岛小屋睡觉”。

### 功能逐步出现

HUD 元素满足条件后才出现，出现时有一个短暂的闪烁（点阵亮两下），日志写一句。条件沿用文字版第 16 节的表，按 2D 调整：

| 元素 | 出现条件 |
| --- | --- |
| 当前目标 | 走出 3 格 |
| 快捷栏 | 拿到第一样东西 |
| 时间 | 开局半小时后 |
| 生命 / 水 / 食物 | 木头 ≥6，或水 < 50、食物 < 45，或造好木筏 |
| 日志 | 第一次有日志 |
| 海图（M） | 第一次出海 |
| 人物面板 | 救出第一位同伴 |

### 不乱的规则

- 同时最多：1 个当前目标、1 条情境提示、1 个高亮、3 条按键提示、3 条日志。
- 提示和卡片不挡住人物和它面前 32 像素。
- 新配方、获救、岛加入网络用全屏弹窗（暂停时间），一次一个，排队显示。

| 夜晚 | 22:00–03:30 | 0 0 0 1 2 2 3 4 0 8 9 11 | 1.00 |

- 时段之间过渡 60 游戏分钟：每个颜色沿自己的色阶一档一档地变，全屏一起变（不用点阵混合两张表，那样看起来像叠了一层网格、分辨率变低）。冷色阶 0–7、暖色阶 8–11 各走各的，跨色阶的在过渡一半时直接换。实现见 `art/palette.ts` 的 `blendTable`。
- 灯光：遮罩范围内读白天那一行。光圈半径（像素，乘灯光强度）：灯塔 13、窗户 12、门灯 10、篝火 26（±1 闪烁）、提灯 7；灯塔光束长 320、夹角 0.2 弧度、每圈 9 秒，强度 < 0.3 时不画。圆心实心，外圈 4 像素棋盘格。
- 雾：浓度 = 离灯塔的距离 + 两层飘动噪声（5 像素/秒），按 Bayer 阈值决定哪里有雾；深浅由噪声决定，大部分是苔雾，噪声高的地方是海雾，所以雾里有一团团云影，不会白成一片。

## 11. 技术架构

### 技术栈

- Phaser 3（WebGL）+ TypeScript + Vite，沿用现有构建、测试（Vitest）和 Cloudflare 部署。
- 世界用 Phaser 画；HUD 和面板用 DOM（React）叠在画布上，按画面倍数 `--k` 缩放，保证文字清楚、方便做中英文。
- 纯前端，无后端，存档在 localStorage。

### 目录

```
src/
  config/     数值、物品、配方、岛屿、村落；新增 buildings.ts（建筑定义）、maps.ts（地图模板）
  i18n/       zh.ts、en.ts（键必须一致）
  sim/        规则层：不依赖 Phaser / DOM，不产出可读文字；所有操作走 dispatch
  art/        调色板、换色表、程序生成的精灵（从设计稿移植）
  game/
    scenes/   Boot、Island、Sea、Map、Cutscene
    world/    岛屿地图生成、碰撞、互动对象、海面
    render/   换色着色器、灯光遮罩、雾、点阵过渡
    input/    键盘、手机摇杆、按键提示
  ui/         DOM 界面层：hud/、panels/、popups/、screens/
  store/      sim 和画面、界面之间的桥：持有 GameState、调度时间、订阅变化
```

### 状态

- `GameState` 必须能 JSON 序列化。2D 版从 `SAVE_VERSION = 1` 重新开始，存档键 `foghaul2d.save.v1`，和文字版分开。
- 新增：`player.scene`（island / sea）、`player.islandId`、`player.x / y / facing`、`raft.x / y`、每座岛的建筑表（槽位 → 建筑）、`tutorial.step`、`seen`（初见介绍记录）。
- 位置这类每帧变化的数据由画面层持有，存档时写回 state；规则只在动作发生时读它。

### 循环

- Phaser 每帧：读输入 → 移动（画面层）→ 累计游戏时间 → 达到 1 分钟就调用 sim 的时间推进 → 画面根据 state 更新。
- 玩家动作：画面层判断“面前是什么”，发出命令 `dispatch(state, { type: 'gather', target })`；sim 校验并结算，返回日志消息。
- 规则层仍遵守 AGENTS.md：文字用 `Msg`，数值只在 config，随机只用 `sim/rng.ts`。

### 渲染管线

1. 场景按**白天调色板**画到一张 480 × 270 的 RenderTexture（地面 Tilemap → 平面装饰 → 按底边 y 排序的物件和人物 → 雾）。
2. 灯光遮罩画到另一张 480 × 270 的纹理（实心圆 + 棋盘格边 + 光束）。
3. 后处理着色器：把每个像素换回 0–11 号，按当前时段的换色表（过渡时用 `blendTable` 逐色换档）上色；遮罩内读白天那一行。
4. 整数倍放大到屏幕，`pixelArt: true`、`roundPixels: true`。
5. 按键提示、地名、“+1”这类世界里的字用像素字体画在画面里；面板文字在 DOM 层。

### 碰撞与互动

- 岛上：每张地图一层碰撞格（16 像素，水和建筑底座不可走）+ 物件的碰撞矩形（树干、建筑底边）。
- 海上：陆地遮罩 + 浓雾遮罩，按像素判断。
- 互动对象有 `kind`、`id`、互动矩形、头顶锚点；每帧找人物前方最近的一个。

### 测试

- 规则层单元测试沿用 Vitest。
- 自动通关测试改成驱动 2D 命令（瞬移到对象旁边再互动），验证主线能走完。
- 冒烟测试：Playwright 打开页面、开新游戏、走几步、出海，确认没有报错。
- 每次改动后跑 `npm test` 和 `npm run build`。

### M1 实现记录

和上文写法有出入、或者上文没写到的地方：

- **碰撞**：移动判定用像素级的可走遮罩（陆地 + 码头，减去物体底座），比 16 像素格子贴合海岸。16 像素一格的可走记录另存一份（`Raster.tiles`），给以后的寻路用。（第 11 节）
- **位置校验**：`sim/interact.ts` 的 `positionError()` 在 `dispatch` 里检查命令需要的物体在不在旁边（采集 → 树 / 浅滩 / 草药丛，制作 → 工作台，涉及仓库的存取 → 储物箱，睡觉 → 小屋，种地 → 农田，修飞机 → 残骸）。海上一律不能制作。还没有地图模板的岛（M3 之前）沿用文字版规则。测试和脚本玩家用 `approach()` 瞬移到物体旁边。
- **地图生成在 `src/world/`**（纯 TS），规则层和画面层共用；`src/game/world/` 只负责把它画出来。
- **画面里的字**（按键提示、初见介绍、“+1”、边缘箭头的距离）用 DOM 叠在画布上，像素字体、按 `--k` 放大，效果和画进画布一样，换语言更省事。
- **引导**：第一天脚本在 `sim/guide.ts`。表里第 3 步和第 4 步之间补了一步“收集木头（n/8）”（捞到鱼但木头还不够 8 根时）。第 6 步是左下角一张卡片，点“知道了”完成。第 7 步起属于 M2。
- **码头**：M1 里按 E 显示“出海（尚未开放）”，灰显。
- **农田**：画成围起来的空地，按 E 显示“需要农民”。
- **点阵过渡**：换色着色器里加了 `uFade`，睡觉和死亡时用 Bayer 点阵变黑再亮起。
- **缩放**：放得下 2 倍的屏幕只按整数倍放大；更小的屏幕（手机）按比例铺满，否则字太小。竖屏手机的布局和触屏操作在 M5。
- **颜色**：界面只有一套深色，用 12 色变量（`--c0` ~ `--c11`），画面里随时段换色的字用 `--w*`。文字版的浅色主题不再保留。
- **调试**：开发模式或 `?debug` 右下角有调试面板，可以只改画面的时刻看换色。
- **走路**：画布按屏幕分辨率渲染、镜头放大 k 倍（像素块大小不变），人物用连续坐标走，任何方向都是 60 像素/秒，斜着走不会更快，也不会一顿一顿。斜着走用左右的行走动画。
- **浪花和雾**：特效层按世界坐标摆放，跟着世界一起动；雾飘得慢、两层同向，浪花的闪烁也放慢，走动时不晕。
- **农田围栏**画成按底边排序的精灵（`game/world/fence.ts`），人物站在围栏后面会被挡住；四边都挡路（`world/island.ts` 的 `fenceRects`，上边挡到横杆）。救出农民后再开门（M4）。
- **篝火火苗和亮着的窗**跟着物体按底边排序（不画在最上层），人物站在前面时不会被盖住。只有天上的东西（炊烟、海鸥、灯光遮罩、雾）画在最上层。
- **浅滩钓点**放在出生点东南的南岸，周围没有树；水面上一直有一圈圈水纹，方便找。
- **采集动画**：树和草药丛跟着节奏摇、掉叶子和木屑；捞鱼时有鱼线、浮漂一沉一浮、水纹变快，捞完溅水花。节奏在 `ANIM.gatherBeat`。
- **提示不挡东西**：选中的东西在人物上方时，按键提示放到脚下；初见介绍卡在物体比人物低时放到物体旁边。
- **快捷栏**每格左上角标数字键；选中的物品（名字、数量，能吃喝时“Q 吃 / 喝 / 用”）显示在右下角的固定卡片里，快捷栏本身不会被挤动。出海后的图例（M2）放在这张卡片上方。
- **人物精灵**绘制位置对齐到屏幕像素，行走帧按走过的距离换，走路时不糊、不像在跑。
