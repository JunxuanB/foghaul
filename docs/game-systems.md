# 玩法系统（按实现）

本文记录每个系统**当前代码里的实际规则**，以及对应的文件和数值键。数值均为 `src/config/balance.ts` 的初始值（`B.` 表示 `BALANCE.`），改数值时以配置文件为准，不必同步修改本文中的数字。

原始设计见 `design/雾屿航线 MVP 游戏方案.md`。实现时补全的设计决定在各节以“补全”标出。

---

## 1. 时间与昼夜

文件：`sim/clock.ts`、`sim/advance.ts`、`store/GameStore.ts` · 数值：`B.time`

- 1 游戏小时 = 现实 37.5 秒。开局为第 1 天 07:00。
- 白天 06:00–19:00，黄昏 19:00–22:00，夜晚 22:00–06:00。
- 每走一格额外推进 7 分钟；采集、制作、培训等行动各有耗时（`B.home`、`B.actions`、配方的 `manualMinutes`）。
- 行动推进的时间对全网同步生效（生产、运输、玩家消耗一起走）。
- 页面隐藏、手动暂停、播放过场时，时间不流逝。
- 傍晚六点（18:00）以后可以在有床的岛上睡觉，直接推进到早上六点（期间玩家消耗减半），醒来生命回满。

## 2. 玩家生存

文件：`sim/advance.ts`（`survive`、`die`、`sheltered`）· 数值：`B.survival`

- 生命、水、食物，上限都是 100。开局 100 / 70 / 60。
- 每小时消耗水 3、食物 2。水或食物为 0 时，分别每小时 −4 / −2 生命。
- 夜晚掉血：在海上每小时 −6；在没床的岛上每小时 −3；在有床的岛、村落或进出口局不掉血（补全）。
- 喝海水：水 +5，生命 −20，耗时 5 分钟。和跳海捕鱼一起常驻在顶栏，随时随地可用（补全）。
- 跳海捕鱼：65% 抓到 1 条鱼，20% 被水母蛰（生命 −8），15% 空手而归；耗时 20 分钟。
- 吃喝：物品的 `eat` 字段（`config/items.ts`）决定恢复量。可以从背包、货舱，或网络内岛屿的库存里吃喝。
- **死亡**（`die`）：货舱普通货物丢一半，背包丢 25%，飞机零件不丢；随船人员回到上次所在的岛；在离死亡地点最近的床（网络内的岛）醒来，生命 50，水和食物至少 30；额外经过 4 小时。

## 3. 地图、迷雾与灯塔探路

文件：`sim/map.ts`、`sim/worldgen.ts`、`sim/reveal.ts`、`config/world.ts`（`REVEALS`）· 数值：`B.map`、`B.buildings.lighthouse`

- 地图 60×36。格子状态：迷雾（黑，不能进入）、可探索（亮着但没去过）、已探索、岛屿。迷雾里的东西永远看不到。
- **只有灯塔能照开迷雾**（补全，回应“每个岛都要修灯塔才能探路”）：
  - 主岛开局自带一座小灯塔，照亮半径 10；
  - 在任何岛（包括村落和礁石，进出口局除外）都能修灯塔，照亮半径按岛等级 11 / 14 / 17；
  - 岛升级时灯塔自动照得更远；
  - 试飞后进出口局周围半径 7 被照亮，并有一条航道连回主岛；进出口局周围半径 3.5 的浓雾在试飞前打不开。
- **灯塔成本递增**：第 1–5 座（不含主岛）分别是 木头 8 / 木头 12 / 木头 16 + 鱼 4 / 木头 20 + 鱼 6 / 木头 25 + 鱼 6，之后一直是最后一档。耗时 90 分钟。
- **照明事件**：`state.lit` 每格记录第一次照亮它的事件编号，每座岛在 `lightEvents` 里记下自己灯塔的事件。这样能区分“这座灯塔新照亮的海域”和“以前就亮着的海域”。
- **岛不是开局生成的**。开局只确定主岛和进出口局的保留位置；其余的岛在解锁时由 `findSpot` 放置：
  1. 只在锚点岛灯塔**新照亮**的格子里找，优先玩家没去过的，离锚点 6 格到（灯塔半径 − 1.5）格，和其他岛至少相隔 7 格，离进出口局足够远，并且从锚点走得到；
  2. 找不到就让这座灯塔再往外照一圈（+3、+6……）再找（实测约 5% 的情况）；
  3. 最后的兜底是任何已照亮的地方。
  - 实测 300 个种子，新岛离锚点 7–13 格（p10–p90），约合 1–1.7 小时航程。
- **解锁顺序**（`REVEALS`，一次一座，每座锚点只用一次）：剧情条件满足**并且**锚点岛的灯塔已经修好，下一座岛才会生成，并给出方向提示。只满足剧情条件时，日志和当前目标会提示“在某岛修灯塔”。

| 岛 | 锚点（要在这里修灯塔） | 剧情条件 |
| --- | --- | --- |
| 石头岛（工程师） | 主岛（自带） | 开局 |
| 森林岛（伐木工） | 石头岛 | 救出工程师 |
| 椰影岛（原住民） | 森林岛 | 救出伐木工 |
| 渔村（渔民） | 椰影岛 | 完成第一次培训 |
| 潮声村 | 渔村 | 救出渔民 |
| 田地岛（农民） | 潮声村 | 渔民学会烤鱼 |
| 麦香村 | 田地岛 | 救出农民 |
| 草药岛（医生） | 麦香村 | 农民学会面包 |
| 信标礁（飞行员） | 草药岛 | 救出医生 |
| 船坞村 | 信标礁 | 飞行员回到主岛 |
| 人力村 | 船坞村 | 工程师学会运输木筏 |
| 白鸥岛（原住民） | 人力村 | 开通第一条运输线 |
| 碎贝岛（原住民） | 白鸥岛 | 招募白鸥岛 |

- 方向提示（“X 岛东北方向约 N 格”）写进 `state.hints`，当前目标会显示它，新岛还会被自动设为航行目标；找到岛后改为显示需求进度。
- **视野**：玩家每到一格，周围 5×5 中已照亮的格子标记为已探索；切比雪夫距离 3 以内、已生成且在可探索海域里的岛被“发现”。
- 每个新存档随机种子；`B.map.fixedSeed` 可以固定。

## 4. 移动与寻路指引

文件：`sim/actions.ts`（`move`、`dock`、`leave`）、`ui/components/MapView.tsx`、`MapPanel.tsx`

- 需要木筏，并且在海上（不靠岸）才能移动，每次一格（上下左右）。
- 航行 Lv5 起可以一次移动两格（`player.twoStep` 开关，默认开）。遇到岛会停下。
- 每格：清除未捞的漂流物、发现新岛、航行经验 +1、推进 7 分钟、可能触发海上事件。
- 走到岛所在格只会提示到达，需要“靠岸”才进入岛屿场景。第一次靠岸时显示岛的介绍文字。
- 航行目标：点地图上的岛或用“选目标”，显示方向、剩余格数和虚线；目标在视野外时，在地图边缘显示提示。不会自动航行。
- 地图三档缩放：15×9 / 25×15 / 35×21，以玩家为中心。

## 5. 海上事件与战斗

文件：`sim/seaEvents.ts` · 数值：`B.sea`

- 靠近进出口局的浓雾时，30% 概率听到“雾里的声音”（幽默线索，不触发其他事件）。
- 否则每格 5% 概率触发事件，按权重抽取：蜜蜂 3、鲨鱼 2（离主岛 <8 格时为 0）、漂流物 3、剧情线索 2（10 条用完后为 0）。
- **战斗**（`combat`）：武力 = 5 + 攻击等级 × 2 + 最好的武器；双方各乘以 0.75–1.25 的随机系数比大小。攻击 Lv3 起有暴击，概率 5% + 每级 5%，暴击直接获胜。
  - 胜：获得掉落（蜜蜂→蜂巢，鲨鱼→鱼），装不下的掉回海里；攻击经验 + 强度。
  - 负：生命 −(8 + 差值)，货物不丢；攻击经验 + 强度的一半。
  - 鲨鱼强度 = 8 + 离主岛距离 / 3。
- **漂流物**：出现“捞起来”按钮，移动或靠岸后消失。前期（对应乘客未获救时）会漂来医疗箱、杯装水；后期偶尔附带幽默文字。
- **剧情线索**：`clue.0`–`clue.9` 按顺序出现，暗示进出口局就在附近和坠机原因（信标被蜜蜂筑巢）。

## 6. 主岛

文件：`sim/actions.ts`（`gather`、`plant`、`harvest`、`installPart`、`repairPlane`）、`ui/scenes/HomePanel.tsx` · 数值：`B.home`

- 掰树枝：木头 +1，20 分钟。救出伐木工后改为砍树：木头 +3，30 分钟。
- 浅滩捞鱼：60% 得 1 条鱼，30 分钟。
- 草药：只有 5 份，每份 15 分钟。
- 采集结果先放进随身背包，满了放木筏货舱，再满了放主岛仓库（补全）。农田收获、手动制作的产物也一样；散装的水只能放进岛上仓库。
- 木筏：是“制作”里的第一个配方（木头 8，60 分钟），开局就会。没有木筏就不能出海，也没有货舱。
- 加固货舱：木头 20 / 35 / 50，每次 +10（30 → 60）。
- 农田（救出农民后开放）：3 块地，播种 15 分钟，24 小时成熟，每块收 6 小麦。种子不作为物品存在。
- 主岛自带床，也是光源。
- 飞机残骸：装零件、修飞机（见第 12 节）。

## 7. 物品、背包、货舱与库存

文件：`sim/inventory.ts`、`config/items.ts` · 数值：`B.inventory`

- 三个存放位置（界面上叫 随身背包 / 木筏货舱 / 岛上仓库，每块都有一句说明）：
  - 随身背包上限 16，采集和制作的东西先进这里，死亡只丢 25%；
  - 木筏货舱上限 30（可加固到 60），造好木筏后才出现；
  - 岛上仓库属于网络内的岛，岛民从这里吃喝、取原料。
- 随船人员 3 人。飞机零件不占容量，总在背包里。
- 物品名带说明气泡（鼠标悬停或点按）：用途、吃喝效果、是否散装（词典 `itemdesc.*`）。
- **三种水**（补全，界面上严格区分名字）：
  - **海水**：不是物品。顶栏“喝海水”随时可用，水 +5、生命 −20；“海水提炼”的原料。
  - **淡水**（`water`）：散装，只能放在网络岛的仓库里，不能装船、不能放背包。玩家和岛民都能直接喝。
  - **杯装水**（`bottledWater`）：淡水 + 杯子 → 杯装水，能带走、交付、装船、走运输线。岛民的饮水需求两者都认。
  - 装杯的入口：仓库里淡水那一行的“装杯 N”按钮（N = 淡水和身上/仓库里杯子数量的较小值，最多 10），或制作页的“装杯”。
  - 自动化：在产淡水的岛（石头岛）由工程师把原住民培训成“装杯”加工，再用运输线把杯装水运到别的岛。
- **库存访问**：只有网络内的岛（`owned`：主岛、获救乘客岛、已招募原住民岛）的库存可以装卸、吃喝。村落和进出口局没有可用库存。
- **仓库上限**（`stockCap`）：每种物品单独计算。岛等级 1/2/3 为 40/80/120；物资接收点让水和食物再 +40；主岛 99；进出口局升级“仓库”整体乘以倍率。
- **交付**（救援、招募、村落请求）从货舱和背包里扣，可以分多次交，进度保存在 `island.needProgress` 或 `village.progress`。需求类型：
  - `item`：指定物品；
  - `food`：任意食物，按 鱼 → 蜂巢 → 烤鱼 → 面包 → 三明治 → 盛宴 的顺序先用便宜的；
  - `drink`：杯装水。
- **成本**（建设、培训、手动制作）从当前岛库存、货舱、背包一起扣（先扣岛上的）。

## 9. 岛屿经济

文件：`sim/economy.ts`、`sim/people.ts` · 数值：`B.economy`

### 设施与产能

- 每座岛一个设施（`island.facility`）：生产某种基础原料（只能在对应群系），或执行一条加工配方（任何群系，建在配方绑定乘客的群系上 +50%）。
- 工人 = 在岛上、能做这个设施工作的人：原住民要被培训成这个工作；乘客要么是该原料的本工种，要么学会了这个配方。
- 每小时产能 = Σ 每个工人的 基础速率 × 倍率：
  - 基础速率：原料看 `B.economy.produceRate`（木头 1.2、鱼 1.0、水 1.5、小麦 1.0、草药 0.6），加工看配方的 `batchesPerHour`。
  - 倍率 = 岛等级倍率（1.0/1.5/2.0；上一顿“凑合”时按低一级）× 终局产能升级 × 群系加成 × 乘客工种等级加成（每级 +15%，该乘客断供时失效）。
  - 断供（上一顿没吃上）时：原住民不干活；乘客只按 1 级倍率干基础产出。
  - 犯困的岛停工。
- 加工只动“居民口粮储备”以外的库存（`spareStock` / `residentReserve`：每人 3 顿的水，以及本级及以下档次的食物；三级岛另留 3 份盐）。
- 产出放不下时标记“爆仓”，加工缺原料时标记“缺原料”（`island.workNote`）。

### 吃饭、升级与生育

- 每天 06:00、14:00、22:00 吃饭（`meal`）。岛上每人（乘客、原住民、在岛上的船员）吃 1 份水和 1 份食物。三级岛每顿另需 1 份盐。
- 食物档次：一级 鱼/蜂巢；二级 烤鱼/面包；三级 三明治/盛宴。先吃本档，再吃更高档，最后用低档凑合。
- 结果（`island.lastMeal`）：
  - `full`：吃饱，连续计数 +1；
  - `partial`：用了低档食物或缺盐，按低一级效率，连续计数清零；
  - `none`：缺水或缺食物，断供。
- 连续吃饱 6 顿，乘客岛和原住民岛升一级（最高 3 级）：产能、仓库、人数上限（2/3/4）提高，同时提高口粮档次。
- 三级岛每天 06:00，若上一顿吃饱且没住满，有 15% 概率生一个孩子（新原住民，直接会本岛的工作）。
- **补全**：往断供的岛卸水或食物，如果够每人吃一顿，大家马上吃（`relieve`），不计入升级进度。避免玩家送完货还要等到下一个饭点。

### 犯困

- 每小时，每座有原住民在干活的岛有 0.6% 概率犯困；管理每级降低 12%（最多降 90%）。全网同时最多一座犯困。
- 犯困的岛停工，玩家必须亲自靠岸点“叫醒”（10 分钟）。

## 10. 人物与人力

文件：`sim/people.ts`、`sim/actions.ts`（`pickUp`、`dropOff`、`train`、`learn`）、`sim/progression.ts` · 数值：`B.progression`

- **玩家属性**：航行（每格 +1 经验，Lv5 一次走两格）、攻击（战斗）、管理（每次培训 +1，降低犯困概率）。经验表在 `B.progression.sail/attack/manage`。
- **乘客**：一种基础产出 + 学会的配方。生产型乘客的经验 = 全网该原料的累计产量；飞行员的经验 = 运输线的累计运量。等级表 `B.progression.passenger`、`B.progression.pilot`。
- **培训 / 转岗**：在网络内的岛上，对已招募的原住民进行。培训的乘客要在场（在岛上或在玩家木筏上），且没有断供。可教的工作（`teachableJobs`）：
  - 本群系的基础原料（乘客群系和岛群系相同时）；
  - 乘客会的加工配方；
  - 飞行员：船员。
  - 消耗：生产 木头 8 + 鱼 4；加工 木头 10 + 杯装水 4；船员 木头 6 + 鱼 4 + 杯装水 4。耗时 1 小时。
  - 培训成生产或加工会把**本岛的设施**改成这项工作；不会新工作的其他人留在岛上但闲着。
- **调配**：接走 / 放下都要玩家靠岸操作。放下受目标岛人数上限约束；可以把人放在网络内的岛和村落。学习中的人不能接走。

## 11. 村落

文件：`config/world.ts`（`VILLAGES`、`WATER_DISPUTE`）、`sim/villages.ts`、`ui/scenes/VillagePanel.tsx`

每个村落有一串固定请求，按顺序完成，每完成一项好感 +1 并发放奖励。

| 村落 | 请求 → 奖励 |
| --- | --- |
| 潮声村 | 鱼 6 + 杯装水 4 → 烤鱼配方；木头 15 + 杯子 6 → 鱼叉（+6）；烤鱼 8 + 木头 10 → 盐配方；盐 6 + 杯装水 10 → 旋翼叶片 |
| 麦香村（只跟农民谈） | 小麦 10 → 面包配方；面包 6 + 烤鱼 6 → 三明治配方；三明治 5 + 盐 5 → 尾桨 |
| 船坞村 | 木头 30 + 医疗箱 3 → 运输木筏配方；三明治 6 + 杯子 10 → 信号枪（+12）；面包 8 + 烤鱼 8 + 盐 6 → 群岛盛宴配方；盛宴 2 → 燃油泵 |
| 人力村 | 鱼 8 + 杯装水 8 → 原住民；面包 6 + 杯装水 8 → 原住民；烤鱼 8 + 医疗箱 2 → 原住民 + 仪表盘；之后可重复：三明治 4 + 杯装水 6 → 原住民 |

- 配方奖励不会直接到手：要把配方绑定的乘客带到村里点“学习”，学 2 小时。学会后乘客可以用它培训原住民，玩家也能手动制作。
- 人力村给的原住民出现在村里，已招募、无业，需要玩家接走。
- **争水源事件**：麦香村好感 ≥2 且已发现人力村时触发；在任一村选边，都能拿到起落架，站人力村多给一个原住民。

## 12. 制作

- 设计方案里“已解锁的配方玩家可以随时合成”：学会的配方都在**制作**标签里（桌面在右栏“物品 / 制作”，手机在底部标签），**随时随地**都能做，海上也可以。

## 13. 运输

文件：`sim/transport.ts`、`ui/dialogs/RoutesDialog.tsx` · 数值：`B.transport`

- **前置**：工程师学会运输木筏配方 → 工程师在场时在网络内的岛上建造（全局计数 `transport.rafts`）→ 飞行员在场时把原住民培训成船员。
- **路线**：两座端点（网络内的岛或进出口局）、一艘木筏、一名空闲船员，去程和回程各设一种货物（或空载）。船从船员所在岛出发，先驶向 A，然后在 A、B 之间往返。
- **航行**：基础 30 分钟一格（曼哈顿距离），飞行员每级 +10%，终局船速升级再乘倍率；船员补给耗尽时降到 40%。
- **靠岸**（30 分钟）：到达时先卸货（受仓库上限和目标库存限制；进出口局直接出口），再补给船员（从当地的余量里取水和食物，各补到 4），然后装下一段的货（载量 20）。
- **装货规则**：只取“余量”（库存 − 居民口粮储备 − 保留量 − 更高优先级路线的预留）；目的地设了目标库存时，只装到目标为止。
- **船员补给**：航行中每 8 小时吃 1 份水 + 1 份食物。
- **飞行员解锁**：Lv2 保留量（岛级设置，`island.reserve`）、Lv3 目标库存（`island.target`）、Lv4 路线优先级（高/中/低）。
- 撤销路线：船上的货卸到当前驶向的岛，船员下船留在那里（若那里是进出口局则回主岛），木筏回到空闲池。
- 海图上画出航线（先横后竖的虚线）和船的位置。

## 14. 终局

文件：`sim/actions.ts`（`installPart`、`repairPlane`、`endCutscene`、`report`、`doExport`、`buyUpgrade`、`fly`）、`sim/endgame.ts` · 数值：`B.endgame`

- 5 个零件：旋翼叶片（潮声村）、尾桨（麦香村）、燃油泵（船坞村）、仪表盘（人力村）、起落架（争水源事件）。
- 在主岛逐个安装，再付 木头 30 + 医疗箱 2，飞行员在场 → 修好直升机，播放试飞过场。
- 过场结束：浓雾散开，进出口局出现，玩家被放在进出口局；主岛和进出口局自带停机坪。
- 点“汇报工作”→ 结局过场与统计 → 进入无尽模式，立即发出第一张订单。
- **出口**：在进出口局把背包或货舱里的货物换成贸易额（单价见 `items.ts` 的 `trade`）。运输线以进出口局为端点时自动出口。
- **订单**：每 2 天一张，限时 3 天，从订单池里随机抽一种货物，数量随已完成订单数增长；完成时额外奖励 2.5 倍货值。
- **永久升级**：船速（+10%/级）、仓库（+20%/级）、产能（+10%/级），各 5 级，费用见配置。
- **停机坪**：修好飞机后可以在网络内的岛上建造（木头 25 + 盐 4）。在有停机坪的岛之间乘飞机，耗时 1 小时，随船人员一起走。

## 15. 目标系统

文件：`sim/objectives.ts`、`ui/components/Objective.tsx`、`ui/dialogs/JournalDialog.tsx`

目标按顺序列出，“当前目标”是第一个未完成的：造木筏 → 救工程师 → 救伐木工 → 第一次培训 → 救渔民 → 渔村灯塔 → 渔民学烤鱼 → 救农民 → 农民学面包 → 救医生 → 送飞行员回主岛 → 第一条运输线 → 集齐零件 → 修飞机 → 汇报 → 无尽订单。

每个目标的说明会按进度变化：没找到时显示 NPC 的方向提示，找到后显示需求进度。目标只是指引，不阻止玩家乱序推进。

## 16. 新手引导

文件：`sim/tutorial.ts`、`ui/screens/`、`ui/components/Tip.tsx`、`ui/dialogs/HelpDialog.tsx`

- **欢迎页**：每次打开游戏先显示，可以选语言和主题，选择继续或开始新的旅程（已有存档时开新局需要确认）。欢迎页和开场剧情期间时间暂停。
- **开场剧情**：新游戏先播放 5 段背景故事（贸易代表、七座直升机上的同伴、大雾坠机），可以跳过；然后是 4 条“怎么玩”。
- **逐步展示**（类似 A Dark Room，`FEATURES`）：界面功能满足条件后才出现，并写一条日志。一旦出现就记在 `state.unlocks` 里，不会再消失。

| 功能 | 出现条件 |
| --- | --- |
| 当前目标、背包 | 掰到第一根树枝 |
| 浅滩捞鱼 | 木头 ≥2 |
| 时钟、昼夜条、日志、暂停 | 开局半小时后（第二件事做完） |
| 制作标签 | 木头 ≥3 |
| 生命 / 水 / 食物 | 木头 ≥6（快能出海时），或水 <50、食物 <45，或造好木筏 |
| 喝海水 | 状态条出现后、水 ≤55，或造好木筏 |
| 采草药 | 捞过鱼或受过伤 |
| 出海、跳海捕鱼、飞机残骸、睡觉 | 造好木筏（睡觉也可以是第一天 18:00 后） |
| “岛屿”面板 | 发现第一座其他岛 |
| “人物”面板、随船人员 | 救出第一位同伴 |
| 建设、主岛仓库 | 第一座岛加入网络 |
| 农田 | 救出农民 |
| “运输”面板 | 救出飞行员 |

- **聚焦引导**（`ui/components/Coach.tsx` 的 `COACH`）：关键时刻把屏幕调暗，只留下要点的那一个按钮或板块，旁边写一句说明。点了高亮的东西或“知道了”就结束，每一步只出现一次（记在 `state.tips`，前缀 `coach.`）。聚焦期间时间暂停，提示框暂时隐藏。顺序：掰树枝 → 时间 → 打开制作 → 做木筏 → 生命水食物 → 出海 → 方向键 → 目标指引 → 靠岸 → 交付 → 修灯塔 → 仓库里的淡水 → 培训 → 运输面板。目标元素用 `data-coach="…"` 标记；目标不在页面上（例如在另一个标签页）时等它出现。
- **新配方弹窗**（`ui/components/RecipePopup.tsx`）：学会新配方时（`learnRecipe` 把它放进 `state.recipePopup`）弹出全屏窗口，列出原料、产物和用途（词典 `recipedesc.*`），可以直接“打开制作”。打开期间时间暂停。
- **自动航行目标**：新岛生成时，如果玩家没有目标或目标已经到过，自动把新岛设为航行目标；选目标列表里也能选已知方向、还没找到的岛。
- **情境提示**（`TIPS`）：只保留需要整段说明的：在海上、天快黑、岛加入网络、三个存放位置、原住民、三种水、村落、犯困、进出口局。同一时间最多一条。
- **帮助**：顶栏“帮助”随时打开，8 节说明（目标、时间与生存、海图与迷雾、背包/货舱/仓库、三种水、制作、岛屿与人、操作）。
- 人物面板只列出已获救或已知下落的同伴，其余只显示“还有 N 位下落不明”。

## 18. 说明气泡

带虚线下划线的名字都可以悬停（手机上点按）查看说明：物品（`itemdesc.*`）、背包 / 货舱 / 仓库标题、建筑（`building.*`，灯塔会显示当前照亮半径）、设施 / 需求 / 升级进度 / 人员（`info.*`）。建设列表里每项建筑下面也直接写着它的作用和成本；所有成本都用黄色高亮。

界面文字（按钮、状态、标签）用中性的书面语，例如“无人工作”“停工（犯困）”“仓库已满”；剧情、日志和角色对白保留口语和幽默。
