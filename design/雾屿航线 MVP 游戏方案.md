# 雾屿航线 MVP 游戏方案

Nov 1, 2026 · @J Bao

## 概述

《雾屿航线》（Foghaul）是一款单人网页文字经营探索游戏。玩家从坠机幸存者起步，靠探索、救人和培训原住民，把散落的岛屿连成自动运转的生产运输网络，最后修好直升机，抵达进出口局履职。

- **核心体验：** 从亲手捡树枝，到看着一张岛屿网络自己运转。
- **表现形式：** 文字驱动加方格地图，几乎不需要美术。第一版是纯前端网页，不需要后端。
- **玩法参考：** Raft 的生存起步、星露谷物语的经营感、狂热运输的路线运输、纪元系列的人口需求。Factorio 只取少量自动化思路。
- **MVP 边界：** 只做单人；在线时实时运行，离线时暂停；全程以物换物，不设通用货币。

## 世界观与主线

主线是找回乘客、修好直升机，最终完成玩家作为贸易代表的使命。

- **背景：** 玩家的国家刚与一个群岛国家建立贸易往来。群岛资源丰富，但技术落后。
- **出发：** 玩家作为进出口贸易代表，与伐木工、农民、渔民、工程师、医生和飞行员同乘一架七座直升机前往该国。
- **开场：** 直升机在即将降落时因大雾迷失方向，坠毁在一座岛上。玩家醒来时不知道自己身在何处，周围只有自己一人、破损的飞机、海边、树林和一片地。
- **主线：** 玩家在迷雾海域中寻找失散的乘客，再向村落换回从天上掉落、被村民捡到的飞机零件。
- **结局：** 飞机修好后，飞行员带玩家飞一圈，再前往进出口局汇报工作，发现它其实就在这片岛屿不远处。

村民对话和海上漂流物要提前暗示进出口局就在附近，并留下坠机原因的线索。全游戏保持一点幽默感，比如海上不知为何会出现蜜蜂。

## 核心循环与玩家动力线

玩家反复经历“探索、解锁、生产、扩张”，每个阶段都把重心从亲手求生推向经营网络。

&#91;embedded content: 核心循环 · 五个步骤\]

| 阶段 | 玩家目标 | 主要行动 | 阶段成果 |
| --- | --- | --- | --- |
| 1. 活下去 | 解决水和食物，离开主岛 | 捡树枝、捕鱼、喝海水、用草药回血 | 造出木筏 |
| 2. 找幸存者 | 找到所有乘客 | 探索海域、交付救援物资 | 资源开始自动产出 |
| 3. 建网络 | 让岛屿互相供给 | 培训原住民、学配方、修灯塔、开运输线 | 岛屿升级，迷雾退去 |
| 4. 修飞机 | 换齐全部零件 | 用整个网络满足村落需求 | 直升机恢复飞行 |
| 5. 履职 | 完成贸易使命 | 向进出口局供货、完成订单 | 贸易额和永久升级 |

中后期的压力来自断供：原住民缺水或缺食物就会停工，玩家要持续维护网络，同时向迷雾深处推进。

## 基础规则

游戏只在玩家在线时运行，昼夜、补给和床共同决定每次出海的节奏。

- **时间：** 在线时实时流逝，现实一天最长 15 分钟，行走、手动采集和制作会让时间加快。离线或页面隐藏时完全暂停，没有离线收益。
- **昼夜：** 夜晚留在外面会受寒风攻击并掉血。
- **睡觉：** 床可以跳过夜晚，并立即结算全网一整晚的产能，同时恢复生命。
- **生存：** 玩家有生命、水和食物三项状态，所有补给都要提前规划。
- **主岛草药：** 开局时主岛有少量草药，可以临时回血，用来撑过第一次出海。
- **海上求生：** 玩家可以喝海水或跳海捕鱼，但都有风险。
- **死亡：** 丢失部分普通货物，然后回到最近的床。飞机零件不会丢失，随船人员回到原岛。主岛自带第一张床。
- **存档：** 后台自动存档。床只负责跳夜和重生，不负责存档。

数值示例（后续再定）：喝一口海水恢复 5 点水，同时损失 20 点生命。捕鱼可能失败，也可能被水母蛰伤。

开局只能徒手行动：用手掰树枝、下水捞鱼、喝海水。后期有工具后可以砍树。种田要等农民获救后才开放，种子不作为物品存在；目前小麦是唯一作物。

## 时间与距离

现实一天最长 15 分钟，走一格约 8 游戏分钟，相邻两岛约 2 游戏小时。这样天黑前能跑 3 趟，每座岛还能停约 2 分钟。以下都是初始值，代码里集中做成可调配置，试玩时再调。

- **时间比例：** 1 游戏小时等于现实 37.5 秒。白天是 06:00–19:00，黄昏是 19:00–22:00，夜晚是 22:00–06:00。
- **行动加速：** 每走一格额外推进 7 游戏分钟。按每秒点 1.5 格计算，加上自然流逝，每格约 8 游戏分钟。手动采集和制作也会加快时间，时长同样放在配置里。
- **全网同步：** 加快的时间对全网生效，生产、需求、运输和玩家的水、食物消耗都会一起推进。
- **运输木筏：** 基础航速为每格 30 游戏分钟，24 格路线约一天往返一次。

地图初始为 60×36 格，相邻岛保持 10–18 格。

| 航程 | 距离（格） | 游戏时间（小时） | 现实点击（秒） |
| --- | --- | --- | --- |
| 相邻岛 | 10–18 | 1.3–2.4 | 7–12 |
| 中程 | 24 | 3.2 | 16 |

| 地图两端 | 64 | 8.6 | 43 |

## 地图与探索

玩家在方格地图上逐格移动，补给和灯塔共同决定能走多远。

| 格子 | 含义 |
| --- | --- |
| 黑色 | 迷雾区域，过于危险，不能进入 |
| 白色 | 可以探索，但尚未抵达 |
| 浅色 | 已探索的空海面 |
| 棕色 | 已发现的岛屿 |

- **移动：** 玩家点击上下左右，每次移动一格。手动跑图是游戏体验的一部分，MVP 不做自动航行。
- **寻路指引：** 玩家可以把任意已发现的岛设为目标。地图只显示方向、剩余格数和虚线，不会自动航行；目标在视野外时，提示显示在地图边缘。
- **靠岸：** 只有走到岛上才出现靠岸操作。
- **缩放：** 地图以玩家为中心，提供三档缩放，分别显示 15×9、25×15 和 35×21 格。
- **岛屿生成：** 位置是在已解锁区域内有逻辑地随机，但发现顺序固定。工程师岛与主岛保持一定距离。
- **扩大范围：** 玩家用物资在岛上修灯塔，灯塔照亮周围迷雾，开放新的探索区域。
- **海面事件：** 大部分行走不会遇到事件，每次移动有小概率触发蜜蜂袭击、鲨鱼袭击、漂流物和剧情线索。
- **漂流物：** 前期会漂来玩家尚未解锁的实用物资，比如医疗箱；后期以剧情线索为主。
- **海上战斗：** 没有逃跑选项，也不需要玩家操作。系统比较武力值和袭击强度，胜利时掉落物资，失败时只扣生命，不丢货物；生命耗尽后按死亡规则处理。

## 岛屿系统

主岛靠玩家亲手采集，其他岛屿靠人力自动运转，每座岛同一时间只做一件事。

| 岛屿 | 作用 |
| --- | --- |
| 主岛 | 唯一能获取多种资源的岛，但只能由玩家手动采集；也是飞机残骸所在地 |
| 乘客岛 | 共六座，救援后乘客开始在岛上生产基础资源 |
| 无业原住民岛 | 岛上只有一名原住民；满足需求后，可由乘客培训成生产或加工岛 |
| 配方村 | 教授加工配方 |
| 人力村 | 提供可以培训成船员的原住民 |
| 进出口局 | 终局目标，接收出口物资 |

### 群系

除主岛外，每座岛都有一种群系。乘客岛的群系固定，原住民岛的群系随机。基础原料只能在对应群系生产。加工可以建在任何岛上，但建在配方绑定的群系上有产能加成（初始示例为 +50%）。每种配方绑定一名培训乘客，加成群系就是该乘客对应的群系。

| 群系 | 基础资源 | 对应乘客 |
| --- | --- | --- |
| 田地 | 小麦 | 农民 |
| 森林 | 木头 | 伐木工 |
| 渔村 | 鱼 | 渔民 |
| 石头岛 | 水 | 工程师 |
| 草药岛 | 草药 | 医生 |

### 岛上建设

- **设施：** 每座岛只有一个设施，要么生产一种原料，要么执行一条加工配方。
- **灯塔：** 一次性建造，用于驱散周围迷雾。
- **床：** 一次性建造，用于过夜、跳过夜晚和重生。
- **物资接收点：** 用物资箱接收水和食物，满足岛民需求，也可以作为玩家的临时补给点。
- **停机坪：** 后期建造，飞机修好后作为快速移动的落点。
- **仓库：** 每座岛都有存储上限，岛民升级时上限提高，不单独做仓库系统。

### 总览面板

玩家可以远程查看所有岛屿的缺货、停工、犯困和爆仓状态。地图用格子底色显示状态，详情放在弹窗里。查看不需要跑图，但处理问题仍要亲自到场或依靠运输线。

## 人物系统

人力是全游戏最核心的稀缺资源：每个人只能生产、加工或开船，玩家要决定把人放在哪里。

### 玩家

玩家有航行、攻击和管理三项属性，都围绕只有玩家能做的事情展开。

- **航行：** 在不同格子间移动时获得经验，升到一定等级后可以一次移动两格。
- **攻击：** 在海上袭击中获得经验，等级提高武力值。达到一定等级后有概率暴击，暴击时直接判定胜利。
- **管理：** 每培训一名岛民获得经验，等级越高，岛民犯困概率越低。

武力值由玩家的武器和攻击等级决定，武器由村落一次性奖励。玩家的木筏可以升级储物空间，提高单次手动运货量。

### 乘客

下表的救援条件是初始示例，难度逐步递进，发现顺序按表格从上到下。

| 乘客 | 产出 | 特殊作用 | 救援条件示例 |
| --- | --- | --- | --- |
| 工程师 | 水 | 教玩家海水提炼；负责建造运输木筏 | 鱼 |
| 伐木工 | 木头 | 玩家不再需要捡树枝；教玩家做杯子 | 食物 |
| 渔民 | 鱼 | 提供稳定食物来源 | 食物、水 |
| 农民 | 小麦 | 教玩家种田，开放主岛农田 | 鱼、其他食物 |
| 医生 | 草药 | 教玩家制作医疗箱 | 食物、水 |
| 飞行员 | 无 | 教原住民开船；飞机修好后负责驾驶 | 医疗箱 |

乘客救出时只有一种基础产出技能，可以被派去村落学习配方来进化，也可以培训原住民。

乘客也消耗水和食物。断供时，乘客只保留基础产出，经验加成失效，也不能培训他人，这样全网不会彻底卡死。只有玩家有生命值和死亡，乘客和原住民都不会死亡，缺物资时只会功能缺失或效率下降。

乘客有自己的经验值。五名生产型乘客按本工种的全网累计产量获得经验，等级提高后，该工种所有岛屿的效率一起提高。飞行员按运输总货量获得经验，等级提高后依次解锁运输设定，并提高运输木筏航速。

### 原住民

- **招募：** 无业原住民需要先得到他们要的物资，才愿意干活。
- **培训：** 乘客必须到场。建设设施和每次培训都要消耗物资，包括第一次培训。这些物资由玩家手动运到岛上。
- **转岗：** 乘客可以把已有原住民重新培训成新工种或新配方，同样要到场并消耗物资。
- **需求：** 原住民持续消耗水和食物。缺少物资时立即停工。
- **升级：** 需求被满足后，岛屿提升等级，获得更高的产能、仓库上限和人数上限，也可能生下小孩，增加一名人力。

原住民偶尔会犯困并停工，必须由玩家亲自到岛上叫醒。管理等级越高，犯困概率越低。同一时间最多一座岛犯困，避免岛屿变多后沦为杂务。

### 人力调配

乘客和原住民都能调到其他岛上帮忙，提高当地产量，但每座岛都有人数上限。调配必须由玩家亲自开船接送。原来的岛如果没人，就会变成空岛。

## 村落系统

村落只分配方村和人力村两类，共用同一套好感规则，飞机零件和武器作为额外奖励。

1. 玩家向村落交付指定物资。
2. 村落好感提升，并开放专属奖励。
3. 玩家或乘客领取奖励，继续推进主线或生产。

| 类型或奖励 | 内容 | 使用方式 |
| --- | --- | --- |
| 配方村 | 教授一条加工配方 | 派配方绑定的乘客到村落学习；学会后玩家也能手动制作，乘客也能培训原住民 |
| 人力村 | 提供原住民人力 | 主要培训成运输木筏的船员 |
| 飞机零件 | 部分村落的高好感奖励 | 交回主岛修飞机 |
| 武器 | 部分村落的一次性奖励 | 玩家获得后可在海上战斗中使用 |

村落还可以触发文字事件，避免每次都只是交物资。例如两村争夺水源时要选边站，或某个村落只信任农民，必须让他本人前来。

## 生产与运输

配方保持简单，所有产物都要进入岛民需求、主线或出口，避免做出来却没有用途。

### 配方表

| 产物 | 原料 | 配方来源 | 培训乘客（加成群系） | 用途 |
| --- | --- | --- | --- | --- |
| 木筏 | 木头 | 玩家初始掌握 | 无，玩家手动制作 | 玩家出海 |
| 水（海水提炼） | 海水 | 工程师获救时教授 | 工程师（石头岛） | 饮用、岛屿供水 |
| 杯子 | 木头 | 伐木工获救时教授 | 伐木工（森林） | 制作可运输的水 |
| 可运输的水 | 水、杯子 | 学会杯子后解锁 | 工程师（石头岛） | 探索补给、运输供水 |
| 医疗箱 | 草药 | 医生获救时教授 | 医生（草药岛） | 玩家回血、救援飞行员、出口货物 |
| 运输木筏 | 木头 | 配方村 | 工程师（石头岛） | 自动运输 |
| 烤鱼 | 鱼 | 配方村 | 渔民（渔村） | 二级需求 |
| 盐 | 水 | 配方村 | 渔民（渔村） | 三级需求、群岛盛宴 |
| 面包 | 小麦 | 配方村 | 农民（田地） | 二级需求 |
| 三明治 | 面包、烤鱼 | 配方村 | 农民（田地） | 三级需求 |
| 群岛盛宴 | 烤鱼、面包、盐 | 配方村 | 渔民（渔村） | 高价值出口货物 |

配方村只教给表中绑定的乘客，学会后玩家也能手动制作。培训时乘客必须亲自到岛上，并且没有断供。飞行员不绑定加工配方，只培训运输木筏的船员。

### 岛民需求分层

| 等级 | 持续需求 | 升级效果 |
| --- | --- | --- |
| 一级 | 水、鱼 | 基础产能 |
| 二级 | 水、面包或烤鱼 | 产能和仓库上限提高 |
| 三级 | 水、三明治、盐 | 再次提高产能，并可能增加人力 |

### 运输木筏

运输线要等至少一条加工配方解锁后再开放，否则只是把原料运来运去。

- **解锁：** 需要村落教授运输木筏配方，由工程师建造。
- **船员：** 飞行员说自己会开船，但不会造船。他负责培训原住民开船，但要守着飞机，不亲自运输。
- **船员补给：** 船员自带少量水和食物，靠岸时从当地岛屿补充。耗尽后航速大幅下降，直到下一次靠岸补给。
- **取舍：** 船员来自有限的原住民人力，所以多开一条航线，就可能少一名生产者。

### 运输规则（暂定）

一条路线只连接两座岛，复杂需求靠增加路线解决。开局只开放路线和货物设置，保留量、目标库存和路线优先级随飞行员等级依次解锁，降低学习成本；岛内优先级始终自动生效。这样规则简单，也让船和船员成为真正的取舍。

1. **路线：** 由 A 岛、B 岛、一艘木筏和一名船员组成，持续往返，耗时按距离计算。
2. **货物：** 去程和回程各设一种货物，也可以空载。一座岛有多种输入或输出时，就开多条路线。
3. **保留量：** 每座岛可以设置每种货物的保留量，低于保留量时不外运，先保证本岛运转。
4. **目标库存：** 目的地可以设置目标库存，达到后暂停运入该货物，避免一直塞满仓库。
5. **路线优先级：** 多条路线抢同一种货物时，按高、中、低分配；同级路线轮流取货。
6. **岛内优先级：** 货物到岛后先满足居民需求，再供应加工，剩余部分才进入外运。

## 终局：进出口局

进出口局把多余资源变成长期目标，也让玩家的贸易代表身份在结局真正落地。

- **解锁：** 修好飞机后，飞行员带玩家抵达进出口局，它随后出现在地图上。
- **快速移动：** 飞行员可以带玩家和人员往返已建停机坪的岛屿。
- **收货：** 所有多余物资都可以运到进出口局。
- **订单：** 进出口局定期指定大宗货物，完成后给予更高回报。订单变化会逼玩家调整网络，形成后期玩法。
- **贸易额：** 只在终局出现，用于永久提升船速、仓库和产能。
- **经济系统：** 贝壳不进入 MVP。到达进出口局之前，所有交换都是物物交换。

抵达进出口局就是完整的游戏体验，不设额外通关节点。之后玩家进入无尽模式，继续完成订单和扩张网络。

## 界面方案

MVP 采用文字优先的 B 方案，布局随玩家所在场景变化，并支持白底和黑底。参考：[界面 Demo](https://claude.ai/artifact/62LMugDTeRxNrw4CQgWBHc)。

| 场景 | 主要内容 | 次要内容 |
| --- | --- | --- |
| 海上 | 事件日志、海图、寻路指引 | 背包、货舱 |
| 在岛上 | 设施、人员、库存、建设、码头 | 背包、货舱 |
| 弹窗 | 人物、岛屿、运输 | 关闭后回到当前场景 |

- **顶部：** 常驻日期、24 小时时钟、白天黄昏夜晚进度条、距离入夜的时长，以及生命、水和食物。
- **操作：** 上排放当下情况的操作，比如捞起漂流物和靠岸；下排常驻喝海水和跳海捕鱼。
- **日志：** 获得的资源和损失用不同颜色高亮。
- **背包和货舱：** 分开显示，每样物品一行，喝、吃、用和卸货按钮放在同一行。

## 技术方案

MVP 是纯前端网页，技术栈为 React、TypeScript 和原生 CSS，不需要后端。

| 用途 | 选择 |
| --- | --- |
| 界面 | React |
| 语言 | TypeScript |
| 样式 | 原生 CSS、CSS Modules、CSS 变量 |
| 地图 | CSS Grid + SVG |
| 弹窗 | 原生 dialog 元素 |
| 构建 | Vite |
| 测试 | Vitest |
| 存档 | 浏览器 localStorage |

- **CSS 框架：** 不使用 Bootstrap 等 CSS 框架。
- **模拟逻辑：** 生产、运输和时间放在 React 外，可以单独测试。
- **数值配置：** 时间、距离和行动时长集中放在配置里，试玩时直接调整。
